### Safra taşı komplikasyonları
| Komplikasyon | Mekanizma / özellik |
| --- | --- |
| **Biliyer kolik** | Taşın geçici sistik kanal tıkanması |
| **Akut kolesistit** | Sistik kanal tıkanıklığı + inflamasyon |
| **Koledokolitiazis** | Taşın ana safra yoluna geçmesi → tıkanma sarılığı |
| **Kolanjit** | Safra yolu tıkanıklığı + enfeksiyon |
| **Biliyer (safra taşı) pankreatiti** | Taşın ampullada tıkanması |
| **Safra taşı ileusu** | Kolesistoenterik fistül üzerinden taşın bağırsağa geçip terminal ileumda tıkaması |
| **Mirizzi sendromu** | Kese boynu/sistik kanal taşının koledoğa bası yapması |
| **Safra kesesi kanseri** | Kronik taş + inflamasyon (porselen kese) |

### Akut kolesistit komplikasyonları
- **Ampiyem**, **gangren**, **perforasyon** (lokal apse veya yaygın peritonit).
- **Amfizematöz kolesistit** (gaz yapan bakteriler, diyabetik).
- Kolesistoenterik fistül.
- Hidrops (tıkalı kesenin sıvıyla dolması).

### Safra taşı komplikasyonları (sıklık sırasıyla, kabaca)
1. **Biliyer kolik** (en sık), 2. **akut kolesistit**, 3. koledokolitiazis, 4. **kolanjit**, 5. **biliyer pankreatit**, 6. Mirizzi, 7. **safra taşı ileusu**, 8. **safra kesesi kanseri**.

### Mekanizmalar
- **Sistik kanal tıkanması:** Kese içi basınç ve safra konsantrasyonu artar → mukozada iskemi ve kimyasal inflamasyon (lizolesitin) → ödem → bakteriyel enfeksiyon → gangren → perforasyon.
- **Koledok tıkanması:** Safra akışı durur → sarılık; enfeksiyon eklenirse kolanjit.
- **Ampulla tıkanması:** Pankreas kanalı tıkanır/safra reflüsü → pankreatit.
