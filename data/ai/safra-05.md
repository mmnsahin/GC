### Sağ üst kadrandaki yapılar
- Karaciğer, safra kesesi ve safra yolları, duodenum, pankreas başı, hepatik fleksura, sağ böbrek ve sürrenal, sağ akciğer tabanı/plevra.

### Sağ üst kadran ağrısı nedenleri
| Sistem | Nedenler |
| --- | --- |
| Safra yolları | Biliyer kolik, **akut kolesistit**, koledokolitiazis, **kolanjit** |
| Karaciğer | Hepatit, karaciğer apsesi, hepatik tümör, Budd-Chiari |
| Mide/duodenum | Peptik ülser, perforasyon |
| Pankreas | Akut pankreatit |
| Böbrek | Pyelonefrit, taş |
| Toraks | Pnömoni, plörezi, miyokard infarktüsü, pulmoner emboli |
| Diğer | Apandisit (yüksek yerleşimli), Fitz-Hugh-Curtis, herpes zoster |

### Yaklaşım
1. **Anamnez:** Ağrının başlangıcı, süresi, yayılımı, yemekle ilişki, ateş, sarılık, idrar/dışkı rengi.
2. **Muayene:** Murphy bulgusu, peritonit bulguları, sarılık, hepatomegali.
3. **Laboratuvar:** Tam kan, CRP, karaciğer fonksiyonları, bilirubin, ALP, amilaz/lipaz, idrar tetkiki.
4. **Görüntüleme:** USG (ilk tercih), gerekirse BT, MRCP, HIDA, ERCP.

### Tıkanma sarılığı
- Direkt (konjuge) bilirubin yüksekliği, ALP/GGT artışı, koyu idrar, soluk dışkı, kaşıntı.
